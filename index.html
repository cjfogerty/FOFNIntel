Each bar’s full height is a location’s deployed capacity (enrolled + open slots): solid = enrolled, faded = remaining open; blue = weekly classes, orange = clinics. Clinics are hidden by default — click the legend (or use the View filter) to show them. The green line is utilization (enrolled ÷ deployed capacity, right axis). The dashed purple line is target enrollment, set at 85% of deployed capacity (left axis, same scale as the bars). Filter by view, day, curriculum category, or level; use Sort By to re-order bars by enrollment, utilization, target enrollment, capacity, or name.
